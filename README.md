# NEXUM - Cyber Security Initiative

Interactive cyber security learning portal built for The Khaitan School.

## Prerequisites

- Node.js (v18 or higher)
- npm

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/bigboi-alt/Cyber-security-project.git
   cd Cyber-security-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
